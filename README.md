# Recall Capture

オンライン会議（Google Meet / Zoom / Discord）と対面授業の音声を記録し、端末内で文字起こしと話者分離を行う個人用macOSアプリです。

保存する全文は `transcript.md`（時刻・匿名話者付き）と `transcript.jsonl`（再処理用の正本）です。Markdownを別ルートでCodexなどへ読み込ませて利用できます。アプリ内の要約とPDF生成は廃止しました。外部APIは組み込んでいません。

## 利用環境とインストール

- Apple Silicon搭載Mac、macOS 15以降。現在はmacOS専用です
- 対象言語のAppleオンデバイス音声認識。macOS 26以降では利用可能な場合にSpeechAnalyzerを使い、それ以外は従来方式を使います
- 従来方式ではシステム設定の「キーボード > 音声入力」もオンにしてください。言語データの初回取得にはネット接続が必要な場合があります

**Apple Intelligenceは不要です。** 音声認識にApple Speech、話者分離に同梱のNemotron 3 Diarizationを使用します。対応するローカル認識が利用できない場合はエラーを表示し、クラウド認識へ切り替えません。アカウント、APIキー、利用者によるHomebrewや証明書の導入は不要です。

配布用ZIPは、Developer ID署名・Appleの公証・Gatekeeper検証を済ませたものを使用します。リリースが公開されたら、添付のSHA-256を確認し、ZIPを展開して `RecallCapture.app` をアプリケーションフォルダに移動してください。現時点で公開済みバイナリは案内していません。公開前の確認項目は [配布手順](RELEASING.md) に記載しています。

## ソースからビルド

開発にはApple Silicon、Swift 6.2以降とmacOS 26以降のSDK（Xcode 26以降、または対応するCommand Line Tools）、Git、CMake、Ninjaを使います。実行対象の最小OSはmacOS 15です。必要なビルドツールは任意の方法で用意できます（Homebrewなら `brew install cmake ninja`）。

```sh
./Scripts/setup-nemotron-diarization.sh
RECALL_CAPTURE_SIGN_IDENTITY=- RECALL_CAPTURE_ALLOW_AD_HOC=1 ./Scripts/build-app.sh
```

セットアップは固定コミットのNeMo-Speech.cppとSentencePieceをビルドし、固定リビジョンのモデルを取得します。モデルのサイズ・SHA-256と実行ファイルの外部依存を検証し、ランタイム、モデル、ライセンスをアプリへ同梱します。利用するMacにPythonやCMakeを入れる必要はありません。

生成物は `.build/RecallCapture.app` と `.build/RecallCapture.zip` です。File Provider管理下のフォルダで署名が妨げられる場合は、ZIPを同期対象外へ展開してください。ad-hoc署名は開発確認用で、更新後に権限の再許可が必要になる場合があります。

同じMacで継続開発する場合のみ、任意で `./Scripts/setup-local-signing-identity.sh` を実行できます。これはログインキーチェーンに開発用証明書を作成し、コード署名の用途で信頼させる操作です。以後は `./Scripts/build-app.sh` が同じ証明書を選びます。標準ビルドは署名証明書がない場合に停止し、ad-hocへ自動で切り替えません。配布版にはDeveloper ID署名と公証を使います。詳細は [CONTRIBUTING](CONTRIBUTING.md) と [RELEASING](RELEASING.md) を参照してください。

起動すると独自の「波形＋赤い録音ドット」アイコンが Dock と Finder に表示されます。メニューバーにも「波形＋Recall」が常時表示され、どちらからでも録音を開始できます。

## 録音と自動停止

オンライン会議はPC音声とマイクを別トラックに、対面授業はマイクを記録します。入力メーターは録音中の音量、「入力なし」「無音」「音声あり」「音量過大」を表示します。音量の検出であり、会話の意味を認識するものではありません。

自動停止は初期設定120分。録音前と設定画面で5〜720分を5分刻みで変更でき、次回起動後も保持します。残り時間を表示し、残り5分・1分で画面、音、Dock、許可済みならmacOS通知で予告します。直近に音声入力がある場合は延長を促します。録音画面、メニュー、通知から15分延長でき、上限は計12時間です。延長しなければ設定時間で停止し、全文の作成を開始します。経過時間にはスリープ中の時間も含み、復帰時に上限を超えていれば停止します。

## 話者付きの全文

録音停止後は音声確定 → オンデバイス音声認識 → ローカル話者分離 → JSONLとMarkdownの検証・保存を行います。

- 音声認識の短い区間と話者の時間帯を照合し、話者の切り替わりで全文を分けます
- Nemotronの `v3-offline` プリセットを使用。トラック全体を無音区間も含めて組み立て、途中で話者番号や時刻がリセットされることを防ぎます
- PC音声とマイクの両方で複数話者を分離。マイクを一律に本人とみなさず、別の話者番号を使います
- 切り替わり付近の小さな時刻ずれを許容し、発話中の声の重なりや判定不足は「不明」として残します
- 話者IDはトラック内・セッション内の匿名ラベルです。氏名や、PCとマイクに現れた同一人物を特定しません
- 話者分離が利用できない場合も全文を保存し、話者を「不明」にして理由を記録します

## 保存と復旧

セッションフォルダには `transcript.md`、`transcript.jsonl`、`transcript-notes.txt`、`recording-manifest.json` と60秒単位の16kHz・モノラル・Int16のCAF音声を保存します。元音声は再処理用に保持します。古いセッションのPDFは削除しませんが、新しい処理では生成しません。

JSONLを正本とし、Markdownはそこから作成します。全文の二ファイルは一時領域で検証してから配置し、保存失敗時は既存の全文を復元します。「後処理を再開」では、有効な保存済みJSONLがあれば音声認識を繰り返さずMarkdownを再作成できます。音声認識の失敗時は元音声から再試行します。注意事項と処理エラーはセッション内に保持します。

## 権限

録音開始時に必要な権限を確認します。対面授業はマイクと音声認識、オンライン会議はそれに加えて画面収録を使用します。「会議ウインドウを読み込む」操作でも、画面収録権限を確認します。この権限は会議ウインドウの取得とPC音声の録音に必要で、画面映像は保存しません。起動や設定表示だけではこれらの許可を要求しません。

設定の「権限とデータ」には用途、現在の状態、対応するシステム設定、「権限を再確認」を表示します。マイクと音声認識の拒否・管理による制限を区別し、拒否後に許可ダイアログを繰り返しません。画面収録APIが返す未許可と未要求は区別できないため、「未確認」と表示します。設定から戻ったときにも状態を再確認します。

画面収録を許可しても反映されない場合は、Recall Captureを完全終了して起動し直してください。再起動後も未確認なら、システム設定の「画面収録とシステムオーディオ録音」で対象アプリを確認してください。署名や配布元を切り替えると再許可が必要になる場合があります。更新時は同じアプリ識別子と署名元を維持しますが、最終的な許可判定はmacOSが行います。

自動停止の予告と延長操作には通知権限を使います。通知を許可しない場合も録音画面の予告、音、Dockによる案内を行います。

## 検証

```sh
RECALL_CAPTURE_SIGN_IDENTITY=- RECALL_CAPTURE_ALLOW_AD_HOC=1 ./Scripts/verify.sh
./Scripts/verify-ui.sh
```

署名付きビルド、権限の許可・拒否・制限分岐、音声チャンクと空白区間、各PCM形式の入力音量、話者切り替え・重複区間・マイクの複数話者、6000発話の全文保存、保存失敗時の復元と再試行、録音上限の予告・延長・停止を検証します。同梱モデルの固定ハッシュ、ランタイムの実行・依存関係、ライセンス、ZIP展開後の署名も確認します。権限検証は模擬応答を使い、実際のmacOSの許可設定を変更しません。UI検証では録音を開始せず各画面を描画します。

実際の日本語会議における認識率と話者判別の正解率は、自動検証とは別に評価が必要です。変更だけを根拠に精度の数値を保証しません。

詳しい操作は [利用ガイド](Resources/UsageGuide.md)、現在の範囲は [仕様](SPECIFICATION_V1.md) を参照してください。
