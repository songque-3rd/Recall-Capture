# Recall Capture

オンライン会議（Google Meet / Zoom / Discord）と対面授業を記録し、端末内で文字起こし・話者分離・要約する個人用 macOS アプリです。

現在は v1 の録音基盤まで実装済みです。操作画面またはメニューバーからオンライン会議のウインドウまたは対面授業用マイクを選び、音声をローカルの音声チャンクとして逐次保存できます。保存先は任意のフォルダへ変更できます。ローカル文字起こし、話者分離、要約、PDF 生成は後続段階で接続します。

## 必要環境

- Apple Silicon Mac
- macOS 15 以降
- Swift 6 以降（ソースからビルドする場合だけ）

## ビルドと起動

```sh
./Scripts/build-app.sh
ditto -x -k .build/RecallCapture.zip "$HOME/Applications"
open "$HOME/Applications/RecallCapture.app"
```

生成物は `.build/RecallCapture.app` と、持ち運び用の署名済み `.build/RecallCapture.zip` です。File Provider 管理下の作業フォルダでは `.app` に Finder 属性が付いて署名検証を妨げる場合があるため、起動・移行には ZIP を展開したアプリを使ってください。別の対応 Mac では ZIP だけを移して展開すれば利用でき、Swift や Homebrew の導入は不要です。個人利用を想定した ad-hoc 署名のため、別の Mac へ移した後の初回起動時は macOS のセキュリティ確認が表示される場合があります。

開発中の再ビルド後も同じプライバシー許可を維持するには、実在するコード署名証明書を指定します。証明書を指定しない ad-hoc 署名では、バイナリが変わるたびに macOS が別のアプリとして扱い、マイクや画面収録の再許可が必要になる場合があります。

```sh
RECALL_CAPTURE_SIGN_IDENTITY="Apple Development: Your Name (TEAMID)" ./Scripts/build-app.sh
```

起動すると独自の「波形＋赤い録音ドット」アイコンが Dock と Finder に表示されます。メニューバーにも「波形＋Recall」が常時表示され、どちらからでも録音を開始できます。

## 録音データ

- オンライン会議: Meet を開いた Safari / Chrome / Edge / Firefox、または Zoom / Discord の選択ウインドウについて、システム音声とマイクを別トラックで保存。候補には現在画面上にある通常サイズ・通常レイヤー・名前付きのウインドウだけを重複なく表示し、ブラウザ名だけの内部ウインドウは除外
- 対面授業: 選択したマイクを保存
- 形式: 16 kHz・モノラル・16-bit PCM (`.caf`)、原則 60 秒ごとのチャンク
- 上限: 3 時間で自動停止
- 保存先: 初期値は `~/Library/Application Support/RecallCapture/Recordings`。操作画面または設定から任意のフォルダへ変更し、次回起動後も維持
- 構造: `<保存先>/<年>/<年-月>/<セッション名>/`
- 安全性: 書き込み中は `.partial.caf` とし、確定後だけ `.caf` に変更

保存先は録音開始前に作成・書き込みテストを行います。録音中は変更できず、変更しても既存セッションは移動しません。現在の保存先は操作画面とメニューバーから Finder で開け、録音停止後は直近のセッションフォルダも表示できます。直近セッションの場所は次回起動後も維持し、移動・削除されていた場合は古い記録を自動的に消去します。

録音中断や書き込み失敗が起きたセッションは削除せず、`recording-manifest.json` と確定済みチャンクを復旧候補として残します。次回起動時にメニューバーと状況画面で候補数を確認できます。

## 権限

マイク録音ではマイク権限、オンライン会議の録音では画面収録とマイク権限を使います。設定画面には現在の判定、システム設定を開くボタン、「権限を再確認」ボタンがあります。許可を変更してアプリへ戻ったときにも自動で再判定します。

## 動画・字幕の扱い

YouTube や bilibili は会議録音とは入力経路が異なるため、v1 には含めません。まずは別アプリに分けず、将来の `動画・字幕を取り込む` モードとして同じ成果物形式へ接続します。ローカル動画、利用者が権利を持つ音声、公式に取得できる字幕の取り込みを先に扱い、サイトからの動画ダウンロードや非公式な字幕抽出は規約・権利・仕様変更の影響が大きいため別途設計します。

## 検証

アプリのビルド、データ保存・復旧、音声のチャンク化、ZIP 展開後の署名をまとめて検証できます。

```sh
./Scripts/verify.sh
```

この検証は SwiftPM に依存せず、macOS 15 SDK と Swift コンパイラを使います。SwiftPM が正常な環境では `swift test` も利用できます。

仕様は [SPECIFICATION_V1.md](SPECIFICATION_V1.md) を参照してください。
